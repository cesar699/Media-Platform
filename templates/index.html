    🍪 会员 Cookie
    在视频网站登录后，把 Cookie 填进来，就能搜/下会员视频。
    获取方式：推荐浏览器装「Get cookies.txt」插件导出 （能拿到按 F12 看不到的 HttpOnly Cookie）；或按 F12 在控制台输入 document.cookie 复制。
    🌐 下载代理
    搜索、下载、直接播放的流量都走这个代理出去。
    适合站点按 IP 封锁的场景（比如 PornHub 拦机房 IP 就报 410）。
    填你的 VPN/代理的 HTTP 或 SOCKS5 地址，例如 socks5://127.0.0.1:1080；留空则不走代理。
